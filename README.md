# a11y-pp102 — скилл для Claude Code: доступность сайтов по ПП РФ № 102

[English version](README.en.md)

Скилл для [Claude Code](https://claude.com/claude-code) (и других ИИ-агентов, читающих Markdown-инструкции), который помогает провести аудит доступности сайта для людей с нарушениями зрения и исправить замечания по требованиям **Постановления Правительства РФ от 07.02.2026 № 102**. В комплекте — расшифровка требований с привязкой к WCAG 2.2, готовые паттерны исправлений, список типовых регрессий, шаблоны таблицы замечаний и журнала правок, а также скрипты автоматической проверки на Playwright.

## Кому это нужно

С 1 марта 2026 года ПП № 102 обязывает обеспечить доступность для инвалидов по зрению официальных сайтов:

- государственных органов;
- органов местного самоуправления;
- **подведомственных им организаций** — государственных и муниципальных вузов, колледжей, школ, детских садов, больниц и поликлиник, музеев, библиотек, театров, МФЦ, других бюджетных, казённых и автономных учреждений.

Для коммерческих сайтов прямой обязанности по ПП № 102 нет, но требования почти совпадают с международным стандартом WCAG 2.2 уровня AA, поэтому методика полезна для любого проекта.

## Что требует постановление

Пункт 2 Требований, подпункты «а»–«н»:

| | Требование |
|---|---|
| «а» | Всё доступно с клавиатуры и программ экранного доступа; структура и порядок определяются программно |
| «б» | Масштабирование текста до 200% без потери функций и горизонтальной прокрутки |
| «в» | Документы читаются скринридером и размечены по ГОСТ Р 70176-2022, либо есть доступная версия |
| «г» | У изображений, видео и другой нетекстовой информации есть текстовая альтернатива |
| «д» | Капча на русском языке и в доступной форме |
| «е» | Заголовки страниц описывают их тему или цель |
| «ж» | Назначение ссылки понятно из её текста или контекста |
| «з» | Контраст текста не ниже 4,5:1 (крупного — 3:1) |
| «и» | Информация передаётся не только цветом, формой или положением |
| «к» | Движущееся и обновляющееся можно остановить; нет мигания, вызывающего дискомфорт (например, более 3 вспышек в секунду) |
| «л» | Наведение указателя не меняет контекст |
| «м» | У полей форм есть подписи, ошибки понятны и доступны скринридеру |
| «н» | Читаемый шрифт без декоративных элементов |

Подробная расшифровка с критериями WCAG и способами проверки — в [`skill/a11y-pp102/references/requirements.md`](skill/a11y-pp102/references/requirements.md).

## Установка

Скопируйте папку скилла в каталог скиллов Claude Code:

```bash
git clone https://github.com/skdimka/a11y-pp102-skill.git
mkdir -p ~/.claude/skills
cp -R a11y-pp102-skill/skill/a11y-pp102 ~/.claude/skills/
```

Или только для одного проекта — в `.claude/skills/` в корне проекта.

Скрипты (нужен Node.js 18+):

```bash
cd a11y-pp102-skill/scripts
npm install
npx playwright install chromium
npm run selftest
```

## Как пользоваться

Примеры запросов в Claude Code:

- «Проверь сайт на доступность по ПП 102, вот список страниц: …»
- «Вот отчёт аудита доступности, пройдись по пунктам с 1 по 20 и исправь»
- «Проверь меню и модальные окна на соответствие подпункту «а»»
- «Составь журнал правок по сделанным исправлениям»

Скрипты напрямую:

```bash
node axe-scan.mjs --urls urls.txt --out reports/axe.md
node reflow-200.mjs --urls urls.txt --out reports/reflow.md --screenshots reports/shots
node keyboard-walk.mjs --url https://example.ru/ --out reports/keyboard.md
```

`urls.txt` — по адресу на строку (`#` — комментарий). Подходят `https://`, `file://` и локальные пути; статическую сборку лучше раздать локальным сервером (`python3 -m http.server`). Параметры: `--width`, `--height` (размер окна, по умолчанию 1280×800), `--zoom` и `--wait` (для `reflow-200`, по умолчанию 2 и 2000 мс), `--max` (шагов Tab для `keyboard-walk`, по умолчанию 300), `--json <файл>` (сырые данные). `npm run selftest` проверяет сами скрипты на тестовых страницах.

## Ограничения и оговорки

- **Это не юридическая консультация.** Скилл помогает выполнить технические требования, но не даёт заключения о соответствии закону. Официальный текст постановления — на [портале правовой информации](http://publication.pravo.gov.ru/document/0001202602100010) (номер опубликования 0001202602100010 от 10.02.2026); при расхождениях действует он.
- **Автоматика не заменяет ручную проверку.** Скрипты находят часть проблем и дают ложные срабатывания; окончательную оценку даёт проверка с клавиатурой и скринридером.
- Проект независимый и не связан с органами власти, проверяющими организациями или разработчиками упомянутых стандартов.
- Все примеры кода, тексты и тестовые страницы написаны для этого репозитория и вымышлены. Репозиторий не содержит материалов, кода или данных третьих лиц и конкретных сайтов.
- Тексты ПП № 102 и ГОСТов пересказаны своими словами со ссылками на источники. Сами ГОСТы в репозиторий не входят.
